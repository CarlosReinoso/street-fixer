The 6 features

  • ASAtlas Search — full-text, fuzzy, autocomplete, facets
  • VSVector Search — semantic / image similarity
  • HYHybrid Search — $rankFusion / $scoreFusion (text + vector)
  • AEAutomated Embedding — Atlas embeds on insert, no pipeline
  • SPStream Processing — real-time windows over event streams
  • VOVoyage AI — multimodal embeddings, reranking

Recommendation: #4 Street Fixer. It uses all 6 features, each for a real job, and has the most visual MongoDB moment: Voyage multimodal vectors collapse duplicate photos ("31 reports → 1 pothole"), and Stream Processing turns incoming reports into live hotspots on the map while the audience watches. The runner-up for the bounty is #1 Claim Appeal, because exact medical codes plus fuzzy descriptions is a natural fit for hybrid search.
From the MongoDB talk: qualify by using MongoDB; you score more for each feature you use and visibly demonstrate. "Focus on the quality of the idea and use case, then build quality. You're not load testing." "Accurate AI is never a model problem": your moat is the data your users generate. Install MongoDB's agent skills in Claude Code / Hermes. The $100 credit runs an M30 (8 GB, dedicated) for ~154 h, enough for the weekend, so pause it after. The speaker said time series and long analytics queries are weak spots, so don't lean on them. Stream Processing wasn't mentioned in the talk.
Demo trick: add an "Under the hood" panel that lights up each Atlas feature (and shows its pipeline) as it runs. Judges score features you can show.
From MongoDB's workshop slides: (1) MongoDB + Voyage in one place: unstructured data → embedding → vector search → reranker → LLM, so include the reranker. (2) Atlas as agent memory: State / Short-term / Long-term ("let's start where we left off", "this customer's history"), with frameworks LangGraph, CrewAI, Autogen and MCP. (3) Automated Embedding is live: text and vector in one collection, and you query in plain English. Credit code: MKT-ENCODELDN-100 (account.mongodb.com → Billing → Apply Code).
Ask Robin/Maja at the booth: which cluster tier supports Automated Embedding? Does the $100 credit cover a Stream Processing instance? How do we get Voyage API access (via an Atlas model API key)?
